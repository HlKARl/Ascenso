ASCENSO 3.4 — Nina integral (23 de octubre de 2026)

NOVEDADES
- Ocho expresiones nuevas de Nina. La expresión pícara hace un guiño y el signo de victoria. Además, la app evita mostrarla demasiado seguido.
- Inicio + Ficha en una sola pestaña. Ninguna estadística, habilidad o insignia se ha eliminado.
- Nina a pantalla dividida: retrato grande arriba y chat desplazable abajo.
- Conexión a Cloudflare Worker, previsualización de rostros y borrado del chat se administran desde el engranaje de Configuración.
- Se mantiene el modo sin conexión; Nina aparece dormida.
- El chat utiliza la misma conexión a Gemini que ya configuraste. No debes modificar el Worker.

INSTALACIÓN
1. En tu versión actual de ASCENSO, entra a Configuración y exporta un respaldo JSON.
2. Descomprime este ZIP. Sube su CONTENIDO (index.html, app.js, style.css, sw.js, plan.json, manifest.webmanifest, icon.svg y carpeta nina/) a la raíz de tu repositorio de GitHub Pages.
3. Espera a que GitHub Pages publique los cambios y vuelve a abrir la app. Si ves la versión antigua, ciérrala por completo y vuelve a abrirla; su Service Worker actualiza la caché.
4. No borres los datos del navegador ni desinstales la PWA antes de exportar tu respaldo: allí están tus progresos, la URL del Worker y el historial de Nina.

PRIVACIDAD
La clave API sigue en tu Worker de Cloudflare. La URL de conexión y las conversaciones siguen guardándose localmente como en la versión anterior. El filtro CORS no impide solicitudes externas directas; para compartir la app públicamente, protege el Worker con autenticación y límites de uso.

NUEVOS RETRATOS
En nina/ encontrarás archivos .webp para ASCENSO. En una carpeta separada del ZIP encontrarás también las versiones PNG, por si deseas reutilizarlas.
