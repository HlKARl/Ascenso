ASCENSO 3.1 — Ajustes y árbol táctil
=======================================
Novedades:
• Desliza el árbol con el dedo en ambas direcciones o utiliza el ratón.
• La ventana del árbol ahora tiene altura limitada para evitar perder el lugar en el celular.
• Botón «Centrar» para regresar al nodo principal.
• El icono superior abre Configuración: acento, fondo, tamaño del árbol, reducir animaciones y respaldos.
• Los respaldos de ASCENSO 3.1 incorporan también las preferencias (compatibles con respaldos viejos).
• Conserva misiones, cronómetro, circuitos, habilidades y progreso de ASCENSO 3.0.

ASCENSO — ACTUALIZACIÓN MINIMALISTA

NOVEDADES
• Nombre único: ASCENSO (sin subtítulos «Proyecto Andy 1.0»).
• Cinco secciones: Hoy, Árbol, Entrenar, Diario y Ficha. La parte financiera está en Diario > Mi dinero.
• Árboles jerárquicos: nacen de un único nodo y se bifurcan con conexiones a habilidades reales. Si el árbol es ancho, desliza horizontalmente.
• 31 habilidades. Cuatro áreas: Personal, Social, Académico y Espiritual.
• Todos los atributos empiezan en 0 en una instalación sin registros. Ninguna habilidad está desbloqueada sin cumplir su requisito.
• En Ficha puedes pulsar cada área para abrir directamente su árbol.
• En Diario se elige una de cuatro áreas y después la acción concreta, que determina los desbloqueos verificables.
• Cronómetro, distancias con operaciones, circuitos, historial, finanzas, respaldos y misiones diarias conservados.
• Las misiones del futuro quedan ocultas. Las anteriores incompletas pasan al día siguiente.

INSTALACIÓN EN GITHUB PAGES
1. Exporta primero el respaldo JSON de ASCENSO actual.
2. Extrae este ZIP y sube los ocho archivos a la RAÍZ del mismo repositorio de GitHub Pages (no a una subcarpeta).
3. Haz Commit Changes en main. Recarga o reabre la PWA cuando GitHub termine de publicar.
4. La URL anterior se mantiene. Se conserva la clave local `andy1_v1`, así que no se borran registros anteriores en ese mismo navegador.
5. Si no aparecen tus registros, importa el respaldo desde Ficha > Respaldo. Importar REEMPLAZA el estado actual.

PRUEBAS Y LÍMITES
• Offline tras una visita con conexión y almacenamiento correcto del service worker. No requiere GPS.
• El cronómetro calcula tiempo transcurrido; en móviles el sistema puede suspender la pestaña. Comprueba tus registros.
• Las capacidades se desbloquean por registros declarados y pruebas registradas. Los atributos son contadores del juego, no mediciones clínicas ni espirituales.
• Al instalar con datos vacíos: 0 habilidades, 0 puntos de atributos. El nivel global de personaje empieza en 1 por convención de RPG.
• Los datos se almacenan localmente, no se sincronizan entre dispositivos.
